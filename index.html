DrawMol

Visualize and build molecular structures with precision. A powerful graphical interface for chemists and researchers on macOS.

Build Structures Effortlessly

Create molecules from scratch by clicking and dragging atoms and bonds. Refine with one-click UFF force field optimization. Auto-detect bond types or set manually, add hydrogens automatically, and export to XYZ, Gaussian, or Gamess formats. Launch Gamess jobs directly if installed.

Advanced Visualization

View structures and properties from XYZ, MDL molfile, Gaussian, Gamess, and more. Display Mulliken charges, dipole moments, NMR shifts, vibrational modes, and molecular orbitals as isosurfaces. Animate normal modes or import Gaussian cube files for density visualization.

Seamless Editing and Import

Paste structures into the Cartesian Editor from XYZ, Gaussian, Gamess, Turbomole, or Z-matrix. Modify atoms, import from ChemSpider, and output in multiple formats. Align molecules or orient axes using least-squares fitting.

Professional Export Options

Save as PNG, TIFF, JPEG, DAE, movies, XYZ, CIF, PDB, or limol (HDF5 with properties). Easily parse limol files in C, Fortran, Python, or dump to ASCII.
